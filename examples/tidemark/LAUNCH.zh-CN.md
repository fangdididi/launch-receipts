# Tidemark 发布包中文概览（虚构示例）

Tidemark 是一个虚构的命令行工具：按拍摄日期重命名照片和视频，先显示预演表，再执行，并写出撤销文件。本文件夹演示了 Launch Receipts 的完整流程，英文原始文件与本概览一一对应。

## 发布卡（SHIPCARD.md）

- **是什么**：按拍摄日期重命名照片和视频的命令行工具，先预演，可撤销。
- **给谁用**：手里有多年相机、手机导出照片，文件名全是 `IMG_4412.JPG` 之类，又不想上传任何东西的人。
- **试用路径**：`pipx install tidemark`，再运行 `tidemark --dry-run ./sample-photos`，看到新旧文件名对照表即为成功。
- **唯一诉求**：在少见的相机上试用，报 Bug 时附上错误原文。
- **不会宣称**："最快""支持所有相机""绝不丢文件"（撤销文件很好用，但它不是备份）。
